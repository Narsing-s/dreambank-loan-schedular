# Security

## Reporting a vulnerability

Please do not publish credentials, tokens, private keys, customer information, or exploit details in a public issue.

For a suspected security issue, use GitHub's private vulnerability reporting/security contact mechanisms available for this repository.

## Data handling

This repository should contain only synthetic/example data. Production customer data and production credentials must never be committed.

## Secrets

Keep Snowflake, SMTP, AWS, API, and deployment credentials outside source control and provide them through secure environment-specific configuration.
