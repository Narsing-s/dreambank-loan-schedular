# Contributing

Thanks for contributing to Dream Bank Loan Scheduler.

## Guidelines

- Keep changes focused and explain the business reason.
- Do not commit credentials, tokens, private keys, or real customer information.
- Prefer synthetic test data.
- Preserve existing Mule flow behavior unless a change is explicitly required.
- Add or update tests for business-rule changes.
- Update relevant documentation when behavior changes.

## Pull requests

A useful pull request should include:

- What changed
- Why it changed
- How it was tested
- Any configuration changes required
- Any known limitations
